`sources/` contains exact pre-consolidation working-tree copies of every planning
document, including existing peer edits. Relative links inside those copies retain
their original document's base; use the linked repository originals or the item
ledger's evidence links when navigating. No historical evidence/log was deleted.
Root documents remain compatibility/history references; only `roadmaps/README.md`
sets current priorities. This avoids breaking source comments and older evidence.

The inventory classifies every task section and explicit checkbox. Ordinary lists
belong to their containing section, retaining the entire original acceptance scope.
Completed and superseded work stays here; partial/needed/certification work routes
to its one live workstream. Historical checked boxes are never used alone to close
physical-device, presentation or operational gates.
