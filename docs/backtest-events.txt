# Archived events for `hookecho --headless-backtest-file docs/backtest-events.txt [volumes]`.
# SITE YYYY-MM-DD HH:MM (UTC). The volumes taken are the ones from that time onward. Each time is
# a few minutes before the first local tornado report for the event, checked against the Iowa
# Mesonet LSR archive (the same reports the backtest scores against). Four of them were once
# typed from memory and wrong by one to six hours - KILX, KLZK, KSGF and KOHX - so their
# 8-volume windows held no tornado at all; check any new line the same way before adding it.
#
# Debris signatures need a correlation-coefficient tilt, which the WSR-88D network only grew
# between 2011 and 2013 (site by site). An event on a radar that predates its own dual-pol
# upgrade has no CC at all - a real limitation of the data, not the detector - and
# `--headless-backtest-file` now leaves such events out of the debris-signature table and says so.
# Keep tornado cases here at or after each site's own dual-pol date unless the point is exactly to
# see that no-CC-data case (KSGF's Joplin miss below is a deliberate example of it).
#
